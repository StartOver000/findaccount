# reports/legacy/ — 历史报告归档（2026-05 ~ 2026-08）

本目录保存 2026-08 及更早的**一次性选号报告 / 候选清单 / 最终购买建议**。
它们对应的是旧数据快照（`data/accounts-final.json` 为 2026-08 批次）、旧榜单与旧脚本，
只用于复盘「当时为什么这么选」，**不要再拿其中的价格/区服/结论当作当前推荐**。

- 现行规范与流程见 `docs/`（入口：`docs/README.md`）。
- 现行报告由 `npm run report` 生成到 `docs/找号报告-<客户>-<日期>.md`。
- 现行策略评估见 `reports/策略落地-20261025/`、`reports/筛选条件策略-20261025/`。
