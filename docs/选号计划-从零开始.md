# 选号计划（从零开始，不受旧数据影响）

## 前提

- 只使用当前浏览器页面 a993380d（不复用旧JSON数据）
- 所有数据通过藏宝阁网站实时采集
- 目标：2000元以内试师赛季性价比最高的账号
- 标准：只看武将是否匹配排行榜强队（T0+ = 10分，T0- = 6分，T1 = 3分）
- 排名规则：得分 ÷ 价格 × 1000 = 性价比分

## 阶段一：设定筛选条件

用当前页面，点击"筛选"按钮进入筛选页，依次设：

**① 区服** → 点"区服" → 选"征服赛季"tab → 逐个勾选以下试师服：
- B组：X5577-X5582（百业争鸣）
- 八阵图：X5644-X5645
- 北伐兴汉：X5660-X5664
- 兵合车错：X5606-X5608
- G组：X5600-X5605（官渡争锋）
- J组：X5625-X5631（金印紫绶）
- J组：X5573-X5576、X5637-X5639（决胜中原）
- J组：X5646-X5651（决战夷陵）
- Q组：X5549-X5554、X5665-X5672（群雄讨董）
- S组：X5533-X5538（四序天象）
- T组：X5555-X5560（太师乱汉）
- T组：X5611-X5615（铁城雄兵）
- X组：X5583-X5588（雪戟冰戈）
- Y组：X5620-X5622（英雄纵横）

**② 价格** → 输入 200 ~ 2000

**③ 不设五星下限、不设武将限制**

**④ 排序** → 价格升序

点击"完成"查看结果。

## 阶段二：浏览候选池

从最便宜的号开始，逐页浏览。

对每个账号只看卡片上的信息：赛季X服、价格、五星数、S战法数、代表武将。

判断标准：
- 优先关注代表武将里出现**曹操、吕蒙、张机、刘备、弓诸葛、晋司马懿**等核心将的号
- 五星数低（<60）但代表武将含核心的 → 值得点开看
- 五星数高（≥90）但代表武将是杂鱼的 → 跳过

每页记录下值得进一步查看的候选。

## 阶段三：点开详情页采集武将卡

只对阶段二筛选出的候选做：

① 点击候选卡片进入详情页
② 点击"武将"标签
③ 截图/记录"部队一"到"部队五"的武将信息和阵容建议
④ 再切换到"武将卡"tab，完整浏览全部五星武将
⑤ 记录关键武将的有无（重点：弓诸葛、晋司马懿、曹操、吕蒙、张机、刘备、孙权等）
⑥ 返回结果页继续看下一个

## 阶段五：算出性价比，排出名次

性价比 = 总得分 × 1000 ÷ 价格

记录前 5 名。

## 阶段六：输出最终推荐

格式：
```
第一名：X服 ¥价格
  藏宝阁链接
  得分：X分
  性价比：X
  核心队伍：...
  
备选：...
```
