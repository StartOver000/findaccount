# 选号条件与筛号流程

## 固定条件

- 只看赛季：X5533-5538，X5549-X5560，X5573-X5588，X5600-X5608，X5611-X5615，X5620-X5622，X5625-X5631，X5644-X5651，X5660-X5672
- 预算优先：2000 元以内
- 常规上限：2500 元以内
- 极限上限：3000 元以内
- 超过 3000 只在性价比明显高时考虑

## 当前摸索结果

- 列表页卡片直接展示：价格、赛季、五星数量、S 级战法数量、稀世宝物数量、满红数、限定数、锻造宝物数、部分代表武将
- 筛选页支持：价格、区服、公示期、阵容建议、武将、五星武将数量、画像、宝物、战法、已锻造宝物数量、资产等条件
- 赛季可以在筛选 > 区服 > 征服赛季里直接多选具体 X 服
- 站内搜索不支持直接搜 X5549 这种赛季号关键字
- 已验证筛选条件会继承保留，可以在同一套条件上持续增减

## 已验证模板

### 模板 A：基础模板

- 赛季白名单：按你的 X5533-5538、X5549-X5560、X5573-X5588、X5600-X5608、X5611-X5615、X5620-X5622、X5625-X5631、X5644-X5651、X5660-X5672 全量勾选
- 价格：小于等于 2500

用途：保留预算内且赛季正确的全部候选池，适合先广扫。

### 模板 B：高性价比初筛模板

- 模板 A 全部条件
- 五星武将数量：大于等于 85
- 已锻造宝物数量：大于等于 12

用途：快速排除大量明显不成型的低价号，适合第一页到前几页的高效扫号。

### 模板 C：定向成队模板

- 模板 B 全部条件
- 再追加 1 到 3 个关键中枢武将

常用追加方向：

- 蜀步/法刀：刘备、诸葛亮、吕蒙、陆逊
- 菜刀/骑兵：张辽、曹纯、马超、吕布
- 法系中枢：曹操、王异、郭嘉、程昱、荀彧
- 当前版本高价值拼图：大乔、张机、袁术、司马师、司马昭

用途：当你想要某类主力队时，直接在高性价比初筛模板上加核心武将。

## 推荐筛号流程

1. 先上模板 A，确认赛季和价格范围都对。
2. 如果结果太多，直接切到模板 B。
3. 如果你要特定玩法，再在模板 B 上叠加关键武将，进入模板 C。
4. 用宝物和战法做二筛，例如博浪、游飘、真刚、垒实迎击、击势、攻其不备等。
5. 列表页优先看卡片上这几项：价格、五星数、S 级战法数、稀世宝物数、锻造数、代表武将。
6. 只对通过这些门槛的号再点进详情页，做队伍成型度和性价比评分。

## 我的后续执行方式

- 先按模板 A 或模板 B 筛出一批候选号
- 再按你当前想要的队伍方向叠加关键武将
- 再结合强度榜评估是否能组出 T0/T0-/T1 主力队
- 最后只给你保留少量高性价比候选号
