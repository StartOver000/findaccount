# 选号计划 v3 — 用排行榜做逐级筛子

## 核心理念

不用手动翻几百个号，而是用排行榜本身当筛子：

**设定"组三队"为目标 → 从低档队伍开始放宽标准 → 逐步提高要求 → 候选池自然缩小到~10个 → 读详情做终决**

## 队伍质量阶梯

| 阶梯 | 包含队伍 | 筛选作用 |
|------|---------|---------|
| 🟢 T1 | 合纵蜀骑、吴弓法刀、五虎队、甘宁流氓、曹操降C法刀、王异菜刀、传统魏智 等 | 第一道宽筛，找"有点基础"的号 |
| 🟡 T0- | 王异法刀、螃蟹队、打火机、三典藏菜刀、于禁蜀步、父子队 等 | 收紧，找"能打"的号 |
| 🔴 T0+ | 庞章鱼、程昱魏智、铁王八 等（排除含弓诸葛/晋司马懿的队） | 最后筛选，找"有强度"的号 |

## 阶段一：设定筛选条件

**使用当前页面 a993380d（不开新页）**

1. 点击"筛选"按钮
2. 区服：逐个勾选试师服（X5533-5538、X5549-X5560、X5573-X5588、X5600-X5608、X5611-X5615、X5620-X5622、X5625-X5631、X5644-X5651、X5660-X5672）— 约60个服
3. 价格：200 ~ 2000
4. 不设五星下限，不设武将限制
5. 排序：价格升序（便宜的先看）
6. 点击"完成"

## 阶段二：第一遍宽筛（T1级别）

浏览结果页，对每个账号看卡片上的代表武将。

**判断标准：** 只要代表武将里出现能组 T1 队的潜力（如曹操、吕蒙、马超、张辽、甘宁、荀彧、郭嘉等），就记录下来。

每页记录名字和价格。目标：收集 20~30 个有潜力的候选。

## 阶段三：第二遍中筛（T0-级别）

对记录下的候选，逐个点开详情页 → 武将页 → 看阵容建议和武将卡。

对照以下 T0- 队伍，检查能否组出至少 3 队：

| T0- 队伍 | 核心武将 |
|---------|---------|
| 王异法刀 | 王异+吕蒙+曹操 |
| 螃蟹队 | 曹彰+曹操+夏侯惇 |
| 打火机 | 陆逊+张机+周瑜 |
| 三典藏菜刀 | 马超+张辽+曹操 |
| 于禁蜀步 | 庞统+刘备+于禁 |
| 父子队 | 孙权+刘备+孙坚 |

**注意：榜单中的诸葛亮必须由弓诸葛（S3）匹配，司马懿必须由晋司马懿匹配**

能组 3 支 T0- 队的留下，不能的淘汰。预期剩下 10~15 个。

## 阶段四：第三遍严筛（T0+级别）

对留下的候选，继续检查能否组出 T0+ 队：

| T0+ 队伍 | 核心武将 | 注意 |
|---------|---------|------|
| 庞章鱼 | 庞统+程昱+张机 | |
| 程昱魏智 | 荀彧+程昱+郭嘉 | |
| 铁王八 | 袁术+刘备+典韦 | |
| 庞统蜀步 | 庞统+刘备+司马懿(晋) | ⚠️ 必须是晋司马 |
| 变种王异刀 | 王异+司马懿(晋)+曹操 | ⚠️ 必须是晋司马 |
| 张飞流氓 | 张飞+弓诸葛+孙权 | ⚠️ 必须是弓诸葛 |

预期剩下 5~8 个 ≈ 目标 10 个左右。

## 阶段五：终决

对最终 ~10 个候选，完整采集：
- 武将卡完整文本
- 战法页完整文本
- 宝物页完整文本

然后一次性跑分排序，得出最终推荐。
