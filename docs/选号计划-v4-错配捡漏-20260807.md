# 选号计划 v4 — 错配捡漏法

> 制定日期：2026-08-07
> 目的：换一套打法找「惊喜号」，突破旧策略的盲区。

---

## 一、旧策略的盲区（为什么要换）

| 旧做法 | 盲区 |
|--------|------|
| 价格升序从头扫卡片 | 卡片只显示代表武将，**核心将在卡面不显示就漏掉**；且从便宜扫到贵，大量时间浪费在垃圾号上 |
| 只按武将分排序（得分×1000÷价格） | 只回答了"武将多不多"，**完全忽略宝物底子**——而宝物是唯一短期补件方向，宝物好的号成长空间完全不同 |
| 一刀切 200~2000 全池子 | 没有分档，低价号和高价号混在一起比性价比，容易错过"贵一点但体验翻倍"的号 |
| 只看在售号，不看上架节奏 | 公示期/新上架号竞争少、卖家常挂低价，是捡漏高发区，旧策略完全没利用 |

---

## 二、核心思路：找「资产-价格错配」号

正常规律：**资产（五星/S战法/宝物/满红）越高，价格越高。**

「惊喜号」= 打破这个规律的错配号：

> **高资产 + 低价格** = 卖家急出 / 挂错价 / 上架期竞争少 → 买到就是赚到

旧策略是"正向扫"（从便宜往贵看有没有好武将），新策略是**"逆向筛"**（先锁定高资产门槛，再看价格有没有错配）。

### Step 2 — 价格分档（不再一刀切）

| 档位 | 价格 | 定位 | 每档目标 |
|------|------|------|---------|
| A 捡漏档 | ≤800 | 赌错配，只收明显低于行情的号 | 2~3 个 |
| B 性价比档 | 800~1200 | 主战场，最可能出惊喜 | 3~4 个 |
| C 均衡档 | 1200~1600 | 即战力与价格平衡 | 2~3 个 |
| D 即战力档 | 1600~2000 | 到手就能打，贵在体验 | 2 个 |
| E 溢价观察区 | 2000~2500 | **只记录不推荐**，除非性价比明显碾压 D 档再上报 | 记录不限 |

> E 档原则：预算最佳 2000，溢价观察区只防止「惊喜号刚好贵一点点」被漏掉。只有该档号性价比明显高于 2000 以内候选时，才提交用户决策，不主动推荐。

### Step 3 — 每档逆向筛选（关键）

#### 3a. 列表页 0 点击初筛（优先，最大提速）

列表页卡片直接展示：价格、五星数、S 级战法数、稀世宝物数、满红数、限定数、锻造宝物数。

用**资产指数**在列表页直接排序，不点详情：

```
资产指数 = 五星数×1 + S战法数×2 + 稀世宝物数×3 + 满红数×5
```

- 对每档：按资产指数从高到低扫列表页，记录指数明显高于同价位同档号的 TOP 号
- 资产指数相同 → 优先看 S 战法数高的（战法是长期短板，战法多更值钱）
- 这一步把「逐号点开」变成「先批量挑，再精点」，样本量可翻数倍

#### 3b. 逆向筛选条件（配合 3a）

对每档设置**高资产门槛 + 该档价格上限**，专门捞错配号：

```
筛选条件：
- 区服：白名单全勾
- 价格：≤ 该档上限
- 五星武将数 ≥ 90（高门槛）
- 已锻造宝物数 ≥ 15（高门槛）
- 阵容建议：勾选系统判定能组强队的选项（若筛选页有）
- 排序：按「最新上架」或「价格升序」切换看两轮
```

- 命中「五星≥90 + 宝物≥15 + 价格却很低」的号 = **候选错配号**，立刻点开详情复核
- 「阵容建议」是平台自己的成队预判，等于免费预筛，优先用
- 如果某档高门槛筛出来全空 → 说明该档没有错配，降门槛到 85/12 再看一轮

#### 3c. 时间维度（两个捡漏窗口）

- 每档用「最新上架」排序看一轮：公示期/新上架竞争少、卖家常挂低价
- 用「即将下架」或检查挂售时长：挂售很久的号不是坑就是贵，直接排除
- 好号秒没，看到错配号不要犹豫，按「下单检查清单」快速走完流程

### Step 4 — 双轴评估（武将分 + 宝物完成度）

候选号进详情页后，不再只算武将分，用**双轴**判断：

- **X 轴 · 武将匹配分**：复用 `strict-version-round1.ps1` 的逻辑，对照强度榜逐队匹配（T0+=10 / T0-=6 / T1=3 / **T2-=1**），**版本武将硬规则不变**（弓诸葛≠诸葛亮、晋司马懿≠魏司马懿）

> ⚠️ 榜单已于 2026-08-07 更新为第三季度版（`队伍强度排行榜.md`）：打火机降 T0-→T2-、狗刀降 T1→T2-，蛋兵衡轲刀改名衡轭菜刀。评分按新档位执行。
- **Y 轴 · 宝物完成度**：T0+/T0- 队伍所需宝物（博浪、游飘、彤素、乌号、徐氏匕首、大檀、承影、元戎等）在宝物页的命中件数

**落点判断：**
| 落点 | 含义 | 价值 |
|------|------|------|
| 高分 + 宝物齐 | 到手即战力拉满 | 最优先 |
| 高分 + 缺少量宝物 | 短期补件就能兑现 | **惊喜号典型** |
| 高分 + 宝物缺很多 | 空有武将库 | 只配当备选 |
| 低分 + 宝物多 | 宝物库虚胖 | 跳过 |

#### Step 4.5 — 反坑核查（防把坑当惊喜）

错配号进入详情后，先回答「为什么便宜」，再算分：

| 核查项 | 坑点 | 处理 |
|--------|------|------|
| 版本武将 | 全是普通版本将，没弓诸葛/晋司马懿/SP 等 | 直接降权，版本硬规则不可妥协 |
| S 战法总数 | 五星多是抽的，S 战法很少（<15） | 战法是长期短板，短期补不动，降权 |
| 红度分布 | 满红全在冷门/四星将上 | 空有红度虚标，参考价值低 |
| 挂售时长 | 挂了很久卖不掉 | 大概率有坑或定价过高，跳过 |
| 副号/挂件 | 同号多角色，主号垃圾副号好 | 确认展示的是主号数据，防挂羊头 |
| 当前公示状态 | 已有人下单/临近下架 | 确认还能不能买，避免白高兴 |

核查通过 → 才进入双轴算分和落点判断。

### Step 5 — 数学上限设定停止条件（防浪费）

参考旧执行计划的做法，先设目标再扫：

- 记录当前已知最佳号（B 档内的最高分/价）
- 新号若不能超过「当前最佳分 ÷ 价格」的性价比，不点开详情
- 每档收集满目标数量即停，不进下一档深挖

### Step 6 — 终决用决策矩阵

各档 shortlist 合并到 ≤5 个，用 `决策矩阵模板.md` 六维加权最终排序：
到手队数30% + 补宝新增15% + 武将库20% + 价格20% + 资产10% + 版本5%

## 四、执行工具链（最终版，2026-08-07 定稿）

| 阶段 | 工具 | 用法 |
|------|------|------|
| ① 列表页初筛 | `find-accounts-20260807.ps1` | `.\find-accounts-20260807.ps1 -SnapshotFile <列表页快照.txt>` → 白名单过滤 + 资产指数排序 + 错配候选 |

> `strict-version-round1.ps1` 已更新：数据路径参数化（-DataPath）、支持 T2- 档位、自动清洗降级标注（打火机/狗刀按 T2- 计 1 分）。
> 旧资产均沿用：`队伍强度排行榜.md`（Q3 版）、版本武将硬规则、浏览器操作守则。

### 正式执行流程（一次会话跑完）

```
1. 页面：进入藏宝阁「全部角色」列表页，确认当前页面可复用
2. 筛选：白名单 X5773-X5899 全勾 + 价格 0-2000，先广扫一轮
3. 快照：read_page → 存列表页快照 txt
4. 脚本：find-accounts-20260807.ps1 → 得到各档资产指数排序 + 错配候选
5. 精选：对每档 TOP + 错配候选，点开详情页（武将 tab）
6. 快照：read_page → 存详情页快照 → cbg_extract.js 提取武将 → JSON

8. 复核：shortlist ≤5 个，人工核对战法/宝物落地状态（Step 4 双轴 + Step 4.5 反坑）
9. 终决：决策矩阵六维加权 → 第一名 + 备选
```
